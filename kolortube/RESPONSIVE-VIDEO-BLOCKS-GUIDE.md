# 📱 KolorTube คู่มืออักษรย่อวิดีโอ Responsive

## ✅ การติดตั้งเสร็จสิ้น
**Responsive Video Block CSS** ได้ถูกเพิ่มลงในไฟล์ `/css/custom.css` โดยอัตโนมัติแล้ว

---

## 🎯 ตำแหน่งการใช้งาน และโครงสร้างไฟล์

### 1️⃣ **ไฟล์ CSS** (ได้รับการแก้ไขแล้ว)
```
/css/custom.css  ← ที่นี่เพิ่มรหัส CSS ตอบสนองแล้ว
```

### 2️⃣ **โหลดโดยอัตโนมัติจากธีม WordPress**
ไฟล์ [inc/enqueue.php](inc/enqueue.php) บรรทัดที่ 43:
```php
wp_enqueue_style( 'wpst-custom-style', get_template_directory_uri() . '/css/custom.css', array( 'wpst-theme-root' ), $style_version );
```

**กำลังโหลดโดยอัตโนมัติอยู่แล้ว!** ✨

## 🔧 วิธีการใช้งาน HTML Template

### **วิธีที่ 1: ใช้งานอัตโนมัติ (แนะนำ)**
ใช้คลาสต่อไปนี้ในแม่แบบลูปวิดีโอของธีม:

```html
<div class="video-block">
    <img src="..." alt="วิดีโอซัมเนล" class="video-thumbnail" />
    <h3 class="video-block-title">ชื่อวิดีโอ</h3>
</div>
```

### **วิธีที่ 2: ใช้ Grid Wrapper**
เพิ่มไปยังองค์ประกอบหลักที่ห้อมรายการวิดีโอ:

```html
<div class="video-block-grid">
    <div class="video-block">...</div>
    <div class="video-block">...</div>
    <div class="video-block">...</div>
</div>
```

หรือ Grid 4 คอลัมน์:
```html
<div class="video-grid-4col">
    <div class="video-block">...</div>
    ...
</div>
```

## 📋 คำอธิบายคำสั่ง CSS ที่ใช้งาน

| CSS Property | บทบาท | ผล |
|---------|-----|------|
| `width: 100%` | ความกว้างการ์ด | ปรับตามหน้าจออัตโนมัติ |
| `height: auto` | ความสูงอัตโนมัติ | เก็บอัตราส่วนรูป |
| `object-fit: contain` | 🔑 **สำคัญ** | แสดงรูปทั้งหมด (ไม่ตัด) |
| `min-height: unset` | ลบข้อ จำกัด ความสูง | ป้องกันการตัดรูปบน-ล่าง |
| `overflow: visible` | แสดงพื้นที่ว่าง | ไม่ซ่อนส่วนใดๆของรูป |
| `-webkit-line-clamp: 2` | จำนวนบรรทัดชื่อ | แสดงชื่อสูงสุด 2 บรรทัด |
| `text-overflow: ellipsis` | วรรค | เพิ่ม "..." ไปยังชื่อยาว |

## 🎨 เคล็ดลับการปรับแต่ง

### เปลี่ยนจำนวนคอลัมน์
แก้ไข `grid-template-columns` ใน `/css/custom.css`:

```css
/* เปลี่ยนเป็น 2 คอลัมน์ */
@media (min-width: 1200px) {
    .video-block-grid {
        grid-template-columns: repeat(2, 1fr);  /* 4 → 2 */
    }
}
```

### ปรับระยะห่าง (Gap)
```css
gap: 16px;  /* เปลี่ยน 16px เป็นค่าที่ต้องการ */
```

### เพิ่มสไตล์ภาพ
```css
.video-block img {
    border-radius: 8px;        /* โค้งมุม */
    box-shadow: 0 4px 8px ...  /* เพิ่มเงา */
    transition: transform 0.3s; /* แอนิเมชั่นเมื่อ hover */
}

.video-block img:hover {
    transform: scale(1.05);
}
```

## ⚠️ การแก้ไขปัญหา

### ❌ "ภาพยังคงถูกตัด"
**วิธีแก้ไข:**
1. ตรวจสอบว่ามี CSS เพิ่มเติมใน `/css/custom.css` หรือไม่
2. ลบแคชเบราว์เซอร์ (`Ctrl+Shift+Delete` หรือ `Cmd+Shift+R`)
3. ลบแคชปลั๊กอิน WordPress หากมี
4. เปิดเครื่องมือนักพัฒนา (F12) → Elements เพื่อตรวจสอบสไตล์ `.video-block img`

### ❌ "เลย์เอาต์ไม่เปลี่ยน"
**วิธีแก้ไข:**
1. ตรวจสอบว่ามีคลาส `.video-block` ใน HTML หรือไม่
2. ตรวจสอบว่า CSS อื่นไม่ได้กำหนดความกว้างของ `.video-block` (ปัญหาความจำเพาะ)
3. เพิ่ม `!important` หากจำเป็น

### ❌ "แท็บเล็ต/มือถือไม่พอดี"
**วิธีแก้ไข:**
1. แก้ไขจุดแบ่ง responsive (ตามการออกแบบของคุณ)
2. ทดสอบเครื่องมือนักพัฒนาด้วยความละเอียดต่างๆ
