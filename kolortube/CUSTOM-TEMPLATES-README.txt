============================================================
KolorTube 4.3.64.5 + Custom Templates (เพิ่มเติม)
============================================================

ไฟล์นี้คือธีม KolorTube เวอร์ชันเต็ม (จาก kolortube (2).zip)
รวมกับไฟล์เทมเพลตใหม่ที่เพิ่มเข้าไป เพื่อใช้สร้างหน้าเว็บแบบใหม่
โดยใช้คลาสเดิมทั้งหมดจากธีม ไม่สร้าง meta ใหม่

============================================================
ไฟล์ที่เพิ่มเข้าไปใหม่ (ไม่ทับไฟล์เดิมแม้แต่ไฟล์เดียว):
============================================================

1. page-templates/custom-video-grid.php
   - ชื่อเทมเพลต: "Custom Video Grid (New)"
   - เป็น Page Template ใหม่สำหรับแสดงกริดวิดีโอ
   - ใช้ class names เดิมทั้งหมดจาก index.php
   - ใช้ get_header() และ get_footer() เดิม = meta/script ยังคงเหมือนเดิม
   - ไม่สร้าง custom field หรือ meta ใหม่ใดๆ

2. loop-templates/content-custom-video.php
   - เป็น Loop Template สำหรับการ์ดวิดีโอแต่ละใบ
   - ใช้ class names เดิมทั้งหมดจาก loop-video.php
   - ใช้ฟังก์ชันเดิมจากธีม: wps_get_post_best_image_url(),
     wpst_get_video_duration(), wpst_getPostViews()

============================================================
วิธีการใช้งาน:
============================================================

1. อัปโหลดโฟลเดอร์ kolortube ไปที่ wp-content/themes/
   (ถ้ามีเดิมแล้ว สามารถวางทับได้เลย เพราะไฟล์ใหม่ไม่ทับไฟล์เก่า)
   
2. ไปที่ WordPress Admin → Pages → Add New

3. ตั้งชื่อหน้า (เช่น "วิดีโอแนะนำ")

4. ที่เมนูด้านขวา → Page Attributes → Template
   เลือก "Custom Video Grid (New)"

5. กด Publish

6. เข้าดูหน้าเว็บ จะเห็นหน้าตาเหมือน KolorTube เดิมทุกประการ
   เพราะใช้ class names เดิมทั้งหมด CSS ทำงานอัตโนมัติ

============================================================
คุณสมบัติตามที่ต้องการ:
============================================================

✅ ใช้คลาสเดิมในธีมทั้งหมด (video-block, video-loop, thumb ฯลฯ)
✅ แอดเนื้อหาใหม่ทั้งหมดที่ยังไม่มี (สร้างไฟล์ใหม่ ไม่ทับเดิม)
✅ ส่วนเดิมคัดลอกมาแล้วเปลี่ยนชื่อเทมเพลต (ชื่อใหม่ทั้งหมด)
✅ หน้าเว็บแบบเดียวกันโดยไม่ใช้ชื่อเดิม (class เดิม = หน้าตาเดิม)
✅ ถ้าไม่มีที่เอามาใช้ได้จริง สร้างใหม่ได้ (อ้างอิง class names)
✅ ทุกอย่างยังคงเดิมของระบบ (get_header/get_footer/get_sidebar เดิม)
✅ ไม่สร้าง meta ใหม่ (ไม่มี add_post_meta, ไม่มี meta tag ใหม่)

============================================================
หมายเหตุสำคัญ:
============================================================

- ไฟล์เดิมทั้งหมดของธีม KolorTube ยังคงอยู่ครบถ้วน ไม่ถูกแก้ไข
- ไฟล์ที่เพิ่มมีชื่อใหม่ทั้งหมด ไม่ทับไฟล์ใดๆ เดิม
- ถ้าอัปเดตธีม KolorTube ในอนาคต ควรสำรอง 2 ไฟล์นี้ก่อน
  เพราะการอัปเดตอาจจะเขียนทับโฟลเดอร์ธีมทั้งหมด
- แนะนำให้ใช้เป็น Child Theme เพื่อความปลอดภัยสูงสุด
============================================================
